# 排查

## 报「未设置 API 密钥」

环境变量没读到。确认：

```bash
echo ${PATENTMAX_API_KEY:0:8}
```

应该输出 `pm_live_` 或 `pm_test_`。空的话：

```bash
export PATENTMAX_API_KEY="pm_live_你的密钥"
```

Windows PowerShell 是 `$env:PATENTMAX_API_KEY="..."`，CMD 是 `set PATENTMAX_API_KEY=...`。

注意 `export` 只对当前终端会话有效，换个窗口要重设。想永久生效写进 `~/.bashrc` 或系统环境变量。

## 401 密钥无效

三种可能：

- **密钥复制不全。** 前后有没有多余空格、有没有漏掉尾部字符
- **少了 `Bearer ` 前缀。** 用 curl 时 header 必须是 `Authorization: Bearer pm_live_xxx`，只写密钥不行
- **密钥被撤销了。** 到 [控制台](https://api.ip930.com/features/api-platform)看状态

> 还有个容易踩的：如果请求里带了 `Authorization` 头，URL 上的 `?apikey=` 就不会被读取。两种方式选一种，别混用——带了一个格式错误的 header，正确的 URL 参数也会被忽略。

## 402 余额不足

到[控制台](https://api.ip930.com/features/api-platform)充值。

新账户的体验额度分两笔：注册送 ¥10，第一次调用成功后再送 ¥40。如果第二笔一直没到，确认第一次调用确实返回了 200——失败的调用不算。

## 404 找不到资源

**查详情时报 404，九成是临时 id 过期了。**

检索返回的 `id` 只活 60 分钟。用脚本的话它有进程内缓存，但跨进程或隔了很久就失效了，重新跑一次检索即可。

用 curl 的话记住：详情类接口只认临时 id，不认公开号。

## 429 限流

`pm_test_` 沙箱密钥每天 30 次。超了会提示改用生产密钥。

生产密钥遇到 429 就等一会儿再试，别死循环重试。

## 检索不到东西

按这个顺序排查：

**一、公开号写法。** 要带国别代码，`CN109761224A` 对，`109761224` 不行。中间不要有空格或横线。

**二、检索式太窄。** 三个条件全用 `AND` 串起来常常一条都没有。砍掉最具体的那个再试。

**三、同义词没扩够。** 中文专利文献里同一个东西常有好几种叫法，还要考虑英文对应词。详见 [query-syntax.md](query-syntax.md)。

**四、真的没有。** 排除以上三条之后才能下这个结论，而且要说清楚：专利从申请到公开有约 18 个月窗口期，这期间的申请谁也查不到。

## 查新任务卡住了

**`--wait` 超时不代表失败。** 任务还在服务端跑，**千万别重新提交**，会再扣一次 ¥15。

用 task_id 继续查：

```bash
python scripts/patentmax_client.py novelty-status --task-id <task_id>
```

深度查新跑十几分钟是正常的，`--depth deep` 更久。

## 查新结果太泛

多半是技术方案描述不够具体。一句「一种新型电池」查不出有用的东西。

至少要有：解决什么问题、用什么手段（具体的结构/材料/步骤/参数）、达到什么效果。

改描述重跑要再花 ¥15，所以**第一次就写细**。描述不够具体时先问清楚再跑，问两三个问题的成本远低于跑一次没用的查新。

## 中文乱码

脚本里已经强制了 UTF-8 输出。如果还乱码，是终端本身的编码问题：

- Windows CMD：先跑 `chcp 65001`
- Git Bash：一般没问题
- PowerShell：`$OutputEncoding = [System.Text.Encoding]::UTF8`

## 没有 Python

`scripts/patentmax_client.py` 只用标准库，Python 3.7 以上都能跑，不需要 pip install。

实在没有 Python 就直接 curl，接口清单和示例见 [api-reference.md](api-reference.md)。

## 沙箱密钥是干什么的

`pm_test_` 开头的沙箱密钥：

- 查新立即返回**模拟结果**，不调用外部服务，不计费
- 检索类每天 30 次

它的用途是**开发阶段验证参数拼得对不对、响应结构长什么样**，跑不出真实检索结果，不能拿来评估数据质量。

正常使用直接走 `pm_live_` 生产密钥——注册送的是真实余额，够跑 500 次检索，不是限次数的试用版。

## 花了多少钱

脚本每次返回都带 `_cost` 字段。准确的用量和流水到[控制台](https://api.ip930.com/features/api-platform)查。

| 调用 | 单价 |
| --- | --- |
| 检索、详情、法律状态、引证、相似专利 | ¥0.10 |
| 权利要求、说明书全文 | ¥0.20 |
| 查新任务（含 DOCX 报告） | 约 ¥15 |

调用失败不扣费。
